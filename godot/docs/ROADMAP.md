# 로드맵: 메인 메뉴부터 한 막 완주까지

목표는 한 번의 여정을 처음부터 끝까지 플레이할 수 있는 틀입니다. 메인 메뉴에서 시작해 슬레이 더 스파이어식 갈림길 맵을 따라 여러 전투·휴식·이벤트를 거친 뒤 보스를 쓰러뜨리면 승리, 파티가 전멸하면 패배합니다.

## 화면 흐름

```text
메인 메뉴 ──새 여정──▶ 맵 ──노드 클릭──▶ 전투 / 정예 / 휴식 / 이벤트 / 보물 / 보스
   ▲   └─이어하기─────▲                        │
   │                  └──────── 클리어 ─────────┘
   ├──────── 보스 격파 → 승리 화면
   └──────── 파티 전멸 → 패배 화면
```

모든 화면 전환은 `SceneRouter.go()`를 거칩니다. 여정 전체의 상태는 `RunState`가 보관합니다. RunState는 3단계에서 도입하며 파티 HP, 골드, 맵, 현재 위치를 가집니다.

## 확정된 설계

| 항목 | 결정 |
|---|---|
| 맵 크기 | 1막 10층 × 5열, 시작 경로 4개 (한 판 15~20분) |
| 이동 | 한 층 위로, 왼쪽 위·위·오른쪽 위 중 연결된 노드만. 경로는 교차하지 않음 |
| 노드 규칙 | 1층 전투, 중간 층 보물, 보스 직전 층 휴식, 정예는 5층 이후, 휴식·정예 연속 금지 |
| HP 유지 | 전투 사이에 HP 유지. 기력·보호막·재사용 대기는 전투마다 초기화 |
| 쓰러진 동료 | 전투 승리 시 HP 1로 일어남 |
| 재현성 | 같은 시드면 같은 맵과 같은 주사위 결과 |
| 전투 판정 | 2d6 + 명중 − 방어. 7~9 스침, 10+ 명중, 치명 기준 이상 치명타 |
| HP 규모 | 레벨 1~2 유닛 10 이하, 레벨 5 이상 정예·보스 20 이상 |

## 단계

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 메인 메뉴, 화면 전환(SceneRouter), 전투·야영지에서 메뉴로 복귀 | **완료** |
| 2 | RunState와 맵 생성 로직(화면 없음). 연결성·비교차·노드 규칙·시드 재현 테스트 | 예정 |
| 3 | 맵 화면(양피지·잉크 길·노드 아이콘), 노드 → 전투 → 맵 복귀, HP 유지, 휴식·정예·보스, 승리/패배 화면 | 예정 |
| 4 | 이벤트(2d6 능력 판정 선택지), 보물, 전투 후 골드와 보상 3택 1 | 예정 |
| 5 | 자동 저장과 이어하기(단일 슬롯) | 예정 |
| 이후 | 상점, 추가 막, 적과 보스 다양화, 상태 이상 | 검토 |

각 단계는 실행 가능한 상태와 자동 테스트 통과를 조건으로 `master`에 반영합니다.
